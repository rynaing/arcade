Contact us

Ryan Cake Studios is run by Ryan Naing. Questions, bug reports, game ideas and feedback are all welcome.

Email: hello@cakecade.com
Ryan reads every message.

What to write about

  • A bug: tell us which game, what you were doing, and whether you were on a phone, tablet or computer. A screenshot helps a lot.
  • A leaderboard name: if a name on a world leaderboard is rude, or it's yours and you want it removed, send the game and the name.
  • An idea: new games, new levels, or anything that would make a game more fun with friends.
  • Privacy: questions about what the arcade stores are answered on the privacy page, and you can email us about anything it doesn't cover.

Bug reports on GitHub

If you have a GitHub account, you can also open an issue at github.com/rynaing/arcade/issues. Please don't post personal information there, since issues are public.

Kids: please ask a parent or guardian before sending us an email.
